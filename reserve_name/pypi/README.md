# runcomposer

**runcomposer** is a tag-based test run composer & orchestrator: see your test
corpus through a curated tag taxonomy, compose precise selections with a real
filter language, and turn a selection into a reproducible, portable *run spec*
that any executor can fulfill — with results flowing back from any transport.

This 0.0.1 release reserves the name while the first functional release is in
development. Watch https://github.com/StochasticEntropy/runcomposer
