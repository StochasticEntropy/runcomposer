# The reviewed lower-case words of this repository (DESIGN.md §12).
#
# tests/test_example_world.py (rule "lowercase-token") checks every
# lower-case word of prose, every hyphenated lower-case identifier wherever a
# host could be written (a job, a cluster or a queue name), every word of a
# JSON text value and of SQL, and the words of every class name, against the
# reviewed vocabulary (tests/example_world_words.txt), the example world, the
# identifiers of the code — and this file. There is no system dictionary: a
# new lower-case word fails the guard until it is added here.
#
# Adding a word is a statement, and needs review: an English (or, for the
# German pages and messages, German) word, or a technical term — never the
# name of a person, a company, a product, a system, a host, a team, a job or a
# cluster from outside this project, whatever its case.
#
# Format: one word per line, matched case-insensitively; "# ..." is a
# comment. Words nothing spells any more are removed (the guard says which).
