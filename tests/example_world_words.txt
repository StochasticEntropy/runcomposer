# The reviewed vocabulary of this repository (DESIGN.md §12).
#
# tests/test_example_world.py checks every capitalised word in prose (and
# every CamelCase, ALL-CAPS or hyphenated-capitalised word anywhere in it)
# against three sources: identifiers of the code, words of the example
# world's demo corpus, and this file. There is no system dictionary: this
# file IS the vocabulary, so a new word fails the guard until it is added
# here, under the heading it belongs to.
#
# Adding a word is a statement, and needs review:
#   * no names of people — this list is people-free (an eponymous technical
#     term is listed as the term, with a comment);
#   * no names of companies, products, systems, hosts or teams from outside
#     this project — a third-party tool is listed only when the project
#     integrates with it by design or its pages target it, with a comment;
#   * example data stays inside the web-shop example world.
#
# Format: "## heading" opens a section; every other non-blank line is one
# word (matching is case-insensitive); "# ..." is a comment. Words nothing
# spells any more are removed (the guard says which).
